# Hackathon MVP scope (contract)

## Must be real (demo-true)

| Area | Requirement |
|------|-------------|
| Flow | One end-to-end path on mobile through Intent → Risk Analysis → Alert → Decision → Containment |
| UX | Risk explanation, alert, decision, containment screens — clear and consistent |
| Story | Narrative that ties the loop together for a judge in one run |

## May be simulated

| Area | Notes |
|------|--------|
| Intent source | Seeded scenarios, forms, or fixtures |
| Risk engine | Heuristics, rules, or stub scoring — must produce believable copy for the UI |
| Chain | Example addresses, amounts, programs — labeled as demo where needed |
| Integrations | Anything not required to tell the safety story |

## Forbidden until post-MVP (do not build)

- Full wallet replacement, portfolio, or “hub” navigation
- Dashboards, charts, or analytics as a product surface
- Enterprise policy, orgs, roles, audit consoles
- Social feeds or multi-user collaboration
- “Support every protocol” before the single flow is undeniable

## Decision rule

If it does not sharpen Intent → Risk Analysis → Alert → Decision → Containment on mobile, it is out.
