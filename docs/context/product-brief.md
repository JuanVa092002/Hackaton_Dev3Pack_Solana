# Product brief

## One-liner

Trustbound Airbag helps users **see risk before they approve** Solana actions, then **decide** and get **containment** guidance if they proceed into danger.

## Problem

Wallet prompts show *what* is being signed, not always *why it matters*. Users need a short, honest risk read before commitment.

## Value

We turn an intent into a guided moment: analyze, alert, decide, contain — optimized for a phone and a tense decision.

## Core loop

Intent → Risk Analysis → Alert → Decision → Containment

## Demo moment

On mobile, a clearly “bad” or sensitive intent is explained in plain language; the user can stop, or continue and see what to do next.

## Users

- Active Solana users in unfamiliar flows.
- Judges and teammates who must “get it” in one walkthrough.

## Differentiation

Depth at the **approval instant**, not breadth across portfolio, analytics, or social.

## Boundaries

Not a full wallet, dashboard product, analytics suite, or enterprise console — see `docs/context/mvp-scope.md`.
