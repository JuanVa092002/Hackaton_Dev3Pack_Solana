# Security Operations

Security work is intentionally simple and trackable.

- `security/testing/` - test checklists and validation notes
- `security/pentest/` - pentest plans and findings
- `security/audit/` - audit preparation and final reports

## Principles

- Keep findings reproducible.
- Keep remediations linked to specific areas (`apps/web`, `apps/backend`, `programs/airbag`).
- Keep security docs concise and review-friendly.
