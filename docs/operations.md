# Operations

## Local workflow

1. Pick a scoped batch.
2. Work in the correct monorepo area.
3. Validate locally.
4. Update handoff notes.
5. Stop for review before next batch.

## Handoff

Use `docs/operations/handoff.md` as the active, replaceable status file.

## Remote policy

This repository can be prepared fully on local machine first.
No push is required while structure and contracts are being stabilized.
