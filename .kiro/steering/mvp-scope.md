# MVP scope (steering)

**Core**

- Single mobile-first flow through: Intent → Risk Analysis → Alert → Decision → Containment.
- User-visible risk explanation, alert, decision, and containment — credible in the demo.

**Nice to have**

- Tighter copy, demo presets, Telegram packaging — only if they do not split focus from the core path.

**Out of scope**

Full wallet, heavy navigation/dashboard, analytics product, enterprise admin, social feeds, broad protocol coverage before the core loop is demo-solid.
