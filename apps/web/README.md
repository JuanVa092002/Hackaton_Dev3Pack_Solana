# Web App (`apps/web`)

Mobile-first frontend for the Trustbound Airbag MVP.

## Scope

- Visual flow only for now.
- API-ready frontend contracts (mock-backed).
- No backend, no wallet adapter, no on-chain writes in this area yet.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and test in a narrow viewport.
